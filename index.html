내 방식 QR

키오스크 앞에서 망설인 적 있나요?
키오스크의 QR을 내 휴대폰으로 찍으면, 내가 정해 둔 방식 — 큰 글씨·쉬운 말·천천히 읽어 주기·큰 버튼·한 가지씩 묻기 — 으로 같은 메뉴, 같은 가격의 주문 화면이 열립니다.

30초 체험 — 한 화면에서 키오스크와 휴대폰 같이 보기 내 방식 정하기(휴대폰) 키오스크 화면(QR이 뜨는 쪽) 매장 운영자 화면(AI 화면 구성안·쉬운 말)

이렇게 씁니다

  1. 내 방식 정하기 — 휴대폰에서 필요한 기능만 고릅니다(장애 여부·병명은 묻지 않습니다). 이 휴대폰 안에만 저장됩니다.
  2. 키오스크의 QR 찍기 — 키오스크 화면의 「내 방식으로 주문」 QR을 휴대폰 카메라로 찍습니다.
  3. 내 화면으로 주문 — 메뉴를 고를 때마다 알레르기 정보를 먼저 보여 주고, 결제 전에 품목마다 한 번 더 보여 줍니다. 어려우면 언제든 「직원 부르기」.
  4. 키오스크로 보내기 — 휴대폰에 뜬 주문 QR을 키오스크 카메라에 보여 주면, 키오스크가 자기 가격표로 다시 계산해 주문 번호를 줍니다. 결제는 키오스크에서.
AI가 하는 일과 하지 않는 일 (자세히)
  • ① 화면 구성안: 매장 메뉴판을 처음 등록할 때, 손님 기능 조합 64가지마다 AI(Qwen2.5-1.5B)가 화면 구성안 — 목록에 보일 정보·한 번에 보일 메뉴 수·설명을 펼칠지 접을지·고를 것을 한꺼번에/하나씩 물을지·글씨와 단추 크기·읽어 줄 것·첫 화면 안내 한 줄 — 을 만듭니다. 코드가 기능별 최소 기준(큰 글씨면 글씨 140% 이상, 큰 버튼이면 단추 140% 이상, 한 가지씩이면 하나씩 묻기, 읽어 주기면 가격·알레르기는 꼭 읽기 등), 고르지 않은 기능은 그대로(또렷한 색은 색만 바꿈), 안내 문장(화면 방식만 — 장애·나이·성분·가격을 말하지 않고 실제 구성과 맞게)을 검사해 고친 뒤 조합별로 저장합니다. 손님 화면은 그릴 때 실제 높이를 재서, 「담기」가 화면 밖이면 그 자리에서 설명을 접고 그래도 넘치면 하나씩 묻습니다.
  • ② 쉬운 말: 메뉴를 등록할 때 AI가 메뉴 설명과 옵션 이름을 쉬운 말로 한 번 바꿉니다. 규칙 검사(원문·용어 사전에 없는 낱말·숫자와 수량·빠진 재료·알레르기 성분을 빼는 말·뜻이 바뀐 옵션·원문에 없는 건강·질병·식이·가격 주장 등)를 통과한 것은 승인 대기로 두고, 매장 운영자가 원문과 나란히 보고 승인한 것만 손님 화면에 냅니다. 통과하지 못하면 쉬운 낱말로 바꾼 매장 설명을, 그것도 어색하면 매장 설명 그대로 씁니다. 규칙은 모두 막지 못합니다 — 규칙을 고정한 뒤 처음 본 틀린 문장 122개 중 119개를 막았고, 맞는 문장도 46개 중 12개를 막았습니다(시험 문장은 모두 AI 페르소나가 씀).
  • 지금 시연의 결과: 두 가지 모두 같은 모델을 개발 PC의 CPU(llama.cpp)에서 돌려 미리 만든 것이고(쉬운 말: 메뉴 30개 중 15개가 AI, 15개는 매장 설명 바탕), 사람이 승인하지 않은 시연용입니다(손님 화면에 「시연용 — 사람 승인 없음」 표시). 운영자 화면의 브라우저 안 실행(WebLLM)은 WebGPU가 있는 기기용 기능으로, 아직 실행 기록이 없습니다.
  • 하지 않는 일: 메뉴 이름·가격·알레르기 정보는 AI가 건드리지 않고 매장 원본 값을 그대로 보여 줍니다(화면 구성안도 이 표시와 「직원 부르기」는 바꿀 수 없음). 매장이 알레르기를 적지 않은 메뉴는 메뉴 설명에 적힌 재료 낱말(우유·밀 등)로 정해진 규칙에 따라 성분을 표시하고 「매장에 확인」을 함께 적습니다. 손님의 설정은 서버에 저장하거나 보내지 않습니다(이 휴대폰 안에만 저장, 주문 QR에도 넣지 않음).

시제품(2026-10) · 가상 매장 「카페 한모금」과 가상 메뉴로 시연합니다(실존 매장·상표 아님). 주문·결제는 실제로 이루어지지 않습니다.
한계: 휴대폰 → 키오스크는 서버 없이 주문 QR로 넘깁니다(키오스크 카메라 또는 사진으로 읽기). 직원 호출과 주문 번호 되돌려 받기는 한 기기 시연 화면 안에서만 됩니다. 시각장애인이 키오스크의 QR을 찾는 방법(음성 안내 버튼·이어폰 잭·점자 안내)은 실제 기기에서 할 일이고, 시제품은 키오스크 화면의 「소리로 안내 듣기」까지만 있습니다. 고령자·장애 당사자 사용성 시험은 아직 하지 않았습니다.
