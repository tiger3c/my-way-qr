# 내 방식 QR (My Way QR)

키오스크 앞에서 망설이는 사람을 위해, 휴대폰에 저장한 **접근성 프로필**(큰 글씨·고대비·쉬운 말·느린 음성·큰 버튼)을 QR로 넘기면 주문 화면이 그 사람 방식으로 바뀌는 시제품입니다.

- 2026 AI 라이프 솔루션 챌린지(산업통상부·한국산업기술기획평가원) 응모용 시제품 — 「AI 라이프 아이디어 챌린지」 수상 후보작 「내 방식 QR」을 구현합니다
- 서버 없음: 정적 웹(GitHub Pages) + 브라우저 안 AI. 장애명·건강 정보는 다루지 않고 '기능 코드'만 씁니다
- 상태: 준비 중(2026-10)

> 이 저장소의 코드와 자료는 열람만 허용합니다. 라이선스는 아직 정하지 않았습니다(권리 관계 확인 중).
